Corn's Corner V4 - Static PWA
Upload this folder to GitHub Pages, Netlify, or another HTTPS static host.
V4: selectable 0 / 3 / 5 / 10-second countdown before Round 1 (default 3); automatic spoken 3-2-1 at the end of each rest.
Pausing works during countdowns and rests. The round clock starts only after the opening countdown.
Existing combination and pace settings preserved from V3.
Speech and background behavior depend on browser and device.

V1.1: Screen Wake Lock on supported browsers while workout runs, with automatic release on pause/reset/end and re-request on return to foreground.

V1.2: Independent countdown/coach voice speed (default natural 1×) while keeping punch callout speed separate.
